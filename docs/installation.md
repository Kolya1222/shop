# Установка пакета

## Простая установка

Совместно с пакетом во внешнем слое поставялется команда по его установке. Включающая в себя набор инструкций выполняемых автоматически.

Выполните команды из директории `/core`:

1. Установка пакета
```bash
php artisan package:installrequire roilafx/shop "*"
```
*Иногда тут возникает ошибка, в таком случае нужно выполнить `composer dump-autoload`, чтобы появились миграции и можно было публиковались скрипты*

2. Выпонить команду и следовать инструкциям
```bash
php artisan shop:install
```

Скрипт сам выполнит все последовательности действий за вас и необходимо будет только перейти на сайт для просмотра результатов.

## Продвинутая установка

При необходимости вы можете выполнить все шаги в ручном режиме. Это даёт полный контроль над процессом и позволяет адаптировать установку под особенности вашего проекта (например, пропустить импорт лишних данных или указать собственный JSON‑файл структуры).

Ниже описаны все этапы, которые автоматизирует команда `shop:install`, но с возможностью тонкой настройки.

### 1. Установка пакета через Composer
```bash
composer require roilafx/shop "*"
```
Если после установки вы не видите миграции или публикуемые ресурсы, выполните сброс автозагрузчика:
```bash
composer dump-autoload
```

### 2. Обновление автозагрузчика (первый раз)
```bash
composer dump-autoload
```
Это гарантирует, что все классы пакета будут доступны для дальнейших команд.

### 3. Применение миграций базы данных
```bash
php artisan migrate
```
Будут созданы таблицы, необходимые для работы магазина.

### 4. Публикация ресурсов пакета
```bash
php artisan vendor:publish --provider="roilafx\\Install\\InstallServiceProvider" --force
```
Опубликуются конфигурационные файлы, шаблоны, сниппеты и другие ресурсы в директории Evolution CMS.

### 5. Импорт структуры сайта (данные магазина из БД)
Это самый гибкий шаг. Вы можете импортировать всё сразу или выборочно.

**Импорт всей структуры (аналог `--all`)**:
```bash
php artisan site:full-import --all
```

**Выборочный импорт**. Используйте комбинацию флагов, чтобы загрузить только нужные типы элементов:
- `--import-resources` – ресурсы
- `--import-templates` – шаблоны
- `--import-tv` – TV‑параметры
- `--import-chunks` – чанки
- `--import-snippets` – сниппеты
- `--import-plugins` – плагины
- `--import-modules` – модули
- `--import-categories` – категории элементов
- `--import-user-roles` – роли пользователей
- `--import-member-groups` – группы пользователей, группы документов и права доступа
- `--import-commerce` – данные компонента Commerce
- `--import-evosearch` – индексы EvoSearch
- `--import-list-tv` – данные ListTV
- `--import-closure` – связи Closure Table

**Дополнительные опции**:
| Опция | Описание |
|-------|----------|
| `--parent=0` | Родительская папка для импорта ресурсов (по умолчанию 0 – корень сайта) |
| `--template=ID` | ID шаблона, который будет назначен ресурсам, если в данных он не указан |
| `--update` | Обновлять существующие элементы вместо создания дубликатов |
| `--preserve-ids` | Сохранять оригинальные ID из JSON (осторожно: могут быть конфликты) |
| `--clear-first` | Полностью очистить соответствующие таблицы перед импортом |
| `--dry-run` | Режим предварительного просмотра – показывает, что будет сделано, без реальных изменений |
| `--file=путь` | Указать свой JSON‑файл с данными для импорта. Если не задан, команда предложит выбрать файл из папки `/assets/import/` |

**Примеры**:
```bash
# Только ресурсы и шаблоны с очисткой существующих
php artisan site:full-import --import-resources --import-templates --clear-first

# Импорт с сохранением ID и обновлением существующих записей
php artisan site:full-import --all --preserve-ids --update

# Предварительный просмотр без изменений
php artisan site:full-import --all --dry-run
```

### 6. Настройка автозагрузки пространства имён
Добавьте в файл `core/custom/composer.json` секцию `autoload.psr-4`:
```json
    "autoload": {
        "psr-4": {
            "EvolutionCMS\\Shop\\": "packages/shop/src/"
        }
    }
```
Если файл отсутствует, создайте его с такой базовой структурой. Это необходимо для работы классов магазина.

### 7. Финальное обновление автозагрузчика
```bash
composer dump-autoload
```

### 8. Очистка кеша (рекомендуется)
```bash
php artisan cache:clear-full
```

После выполнения всех шагов магазин полностью установлен и готов к работе.

## Перенос готовой структуры с другого сайта

Если у вас уже есть настроенный магазин на другом экземпляре Evolution CMS, можно быстро скопировать всю его начинку (ресурсы, шаблоны, TV‑параметры, чанки, сниппеты, плагины, модули, категории, данные Commerce, EvoSearch, ListTV, роли пользователей, группы и права доступа из БД) на новый проект. Для этого используется пара команд: **экспорт** на исходном сайте и **импорт** на целевом.

### Экспорт с исходного сайта
На сайте-источнике выполните в консоли (из директории `/core`):
```bash
php artisan site:full-export --all --output=my_shop.json
```
Флаг `--all` экспортирует всё, что нужно для полного переноса магазина. При необходимости вы можете выборочно экспортировать только определённые компоненты, заменив `--all` на один или несколько флагов:
- `--with-resources`
- `--with-templates`
- `--with-tv`
- `--with-chunks`
- `--with-snippets`
- `--with-plugins`
- `--with-modules`
- `--with-categories`
- `--with-closure`
- `--with-commerce`
- `--with-evosearch`
- `--with-list-tv`
- `--with-user-roles`
- `--with-member-groups`

Дополнительные параметры экспорта:
- `--parent=ID` – начать с определённого родителя (по умолчанию 0 – всё дерево);
- `--depth=10` – ограничить глубину вложенности ресурсов;
- `--with-deleted` – включить удалённые ресурсы;
- `--pretty` – отформатировать JSON для удобства чтения.

Созданный файл появится в папке `assets/export/`. Скопируйте его на целевой сайт, в `assets/import/`.

### Импорт на целевом сайте
На новом сайте выполните импорт из этого файла (в предложенном списке выберите скопированный вами файл):
```bash
php artisan site:full-import --all
```
Для более точного переноса используйте дополнительные опции:
- `--update` – обновлять существующие элементы, а не создавать дубликаты;
- `--preserve-ids` – сохранить оригинальные ID из JSON (удобно, если вы переносите связанные данные и хотите избежать нарушения ссылок);
- `--clear-first` – полностью очистить соответствующие таблицы перед импортом.

После успешного импорта выполните финальный сброс автозагрузчика и очистку кеша:
```bash
composer dump-autoload
php artisan cache:clear-full
```

Таким образом вы можете легко клонировать магазин между проектами или создавать резервные копии структуры для быстрого развёртывания.
